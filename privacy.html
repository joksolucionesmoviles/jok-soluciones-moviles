Política de Privacidad - JOK Soluciones Móviles

Última actualización: 9 de octubre de 2026

JOK Soluciones Móviles utiliza herramientas y APIs oficiales de plataformas como Meta y TikTok para gestionar mensajería, atención comercial y publicación de contenido audiovisual.

Cuando un usuario interactúa con nuestros canales o autoriza una conexión con TikTok, podemos procesar información técnica necesaria para prestar el servicio, incluyendo identificadores de cuenta, tokens de acceso, datos básicos del perfil autorizados por la plataforma y contenido audiovisual destinado a publicación.

En el caso de TikTok, la aplicación puede utilizar permisos autorizados por el usuario para cargar contenido audiovisual mediante la API oficial de TikTok Content Posting.

La información recibida se utiliza únicamente para operar las herramientas de JOK Soluciones Móviles, responder consultas comerciales, automatizar determinadas tareas y publicar contenido propio en las cuentas autorizadas.

Podemos utilizar proveedores tecnológicos como Meta, TikTok, Make, OpenAI y otros servicios necesarios para operar estas automatizaciones.

JOK Soluciones Móviles no vende información personal ni utiliza los datos recibidos para fines ajenos a la operación de sus servicios.

Los datos se conservan únicamente durante el tiempo necesario para prestar el servicio, cumplir obligaciones legales o resolver consultas y reclamos.

Los usuarios pueden revocar los permisos otorgados desde las herramientas de configuración de cada plataforma.

Para solicitar acceso, corrección o eliminación de datos, los usuarios pueden comunicarse a: joksolucionesmoviles@gmail.com
